# Baby Interim — Workout Lookup

Tap a section. Loads are what you were already doing — **hold them, don't chase them.**

<details open>
<summary>⚡ THE DEFAULT — 30 min, full body</summary>

Flow → strength → finisher. If you only ever run this one, the interim period is a success.

| Block | What | Load |
|---|---|---|
| **1. Flow** ~10 min | Any one of the four, both sides, 2-3 rounds | 25-35 |
| **2. Strength** ~10 min | KB press 8/8 · KB row 8/8 · KB curl 8/8, 3 rounds | press 50 · row 50 · curl light |
| **3. Finisher** ~10 min | Brutal Complex **or** figure-8 → tactical clean | 35 · 50 |

**Cut it to 20 min:** drop the finisher. **Cut it to 10:** flow only.

</details>

<details>
<summary>💪 PUSH — 25-30 min</summary>

| Exercise | Load | Sets |
|---|---|---|
| Incline DB press | **55** | 3 × 8-12 |
| DB shoulder press (strict) | 35-45 pair | 3 × 8 |
| Push-up or DB floor press | bodyweight / 45 | 3 × 10-15 |
| DB lateral raise — slow, 1s hold | **15-17.5** | 3 × 15 |
| Overhead tricep ext (DB or cable) | pick by feel | 3 × 12 |

🛑 **Overhead is the first thing to cut on bad sleep.** Drop the shoulder press, keep the incline.
🔥 Lateral raise + tricep can go near failure on the last set.

**No dip bars?** Push-ups with a slow eccentric cover it.

</details>

<details>
<summary>🎣 PULL — 25-30 min · the highest-value day right now</summary>

This is the one that undoes a day of one-armed carrying. **If a week only gets one gym day, make it this one.**

| Exercise | Load | Sets |
|---|---|---|
| Pull-ups — 3s eccentric | bodyweight | 4 × to form failure |
| DB row (left first) | **70 / 80 / 90** | 3 × 8-10 |
| Chest-supported row on incline bench | **45** | 3 × 12, slow ecc |
| Incline curl (left first) | **25** | 3 × 10 |
| DB reverse fly | **20** | 3 × 12-15, slow ecc |
| Face pull (if the cable exists) | light | 3 × 15, high elbows, rotate at the end |

🛑 Pull-ups, rows, curls — the cue is the cap. 🔥 Reverse fly + face pull can push.
**No cable?** Band pull-aparts or a prone Y on the bench. Don't skip the rear-delt work.

</details>

<details>
<summary>🦵 LEGS — 25-30 min</summary>

No rack and no barbell, so the back squat is out. Nothing else changes much.

| Exercise | Load | Sets |
|---|---|---|
| Goblet or KB front squat — full depth | 50-70 | 3 × 8-10 |
| Bulgarian split squat | **double-50 DBs** | 3 × 8-10 each |
| Leg press (upright machine) | find it — shorter ROM than Arrillaga | 3-4 × 12 |
| Nordic curl — eccentric only | bodyweight | 3 × 3-5 |
| DB RDL — 3s down, 2s pause | 50-70 pair | 3 × 12 |
| Calf raise | bodyweight or DB | 3 × 15, hold the stretch |

**Watch the right front leg on Bulgarians** — it was dying from rep one, and it felt like trunk more than quad.

</details>

<details>
<summary>🌀 FLOWS — 10-15 min each, single bell</summary>

All four, both sides, 2-3 rounds. Bell **25-35** — heavier only if the day is good.

| Flow | Chain | Bias |
|---|---|---|
| **Bent Press Flow** | dead clean → front squat → lateral lunge → bent press → tactical clean | full body, overhead |
| **Leggy Flow** | dead clean → curtsy lunge → lateral lunge → lateral squat clean → lateral lunge → tactical clean | legs, **no overhead** |
| **B-Stance Flow** | b-stance swing → swing clean → ab-stance goblet squat → swing snatch → overhead lunge | hinge + single-leg, hard |
| **Outside Snatch Flow** | figure-8 → tactical clean → transverse lunge → outside snatch → windmill → snatch → thruster → deep squat press → hand-to-hand swing | long, core-heavy |

**On the worst-sleep days pick the Leggy Flow** — nothing goes overhead in it.
**The B-Stance Flow is conditioning, not skill work.** Don't treat it as the easy option.

</details>

<details>
<summary>🔥 COMPLEXES + FINISHERS — 8-12 min</summary>

| Block | Moves | Load |
|---|---|---|
| **Brutal Complex** (3 rounds, ~10-12 reps each) | swing → ab-stance goblet squat → alternating bent-over row → close-grip pushup on the bell | **35 — not more** |
| **Figure-8 → tactical clean** | continuous loops, both directions | **50**, 3-4 loops |

**Brutal Complex pacing:** the squats and the pushups are the whole difficulty. The swing and the row are the rest.
**Rounds are the variable, not the bell.** Stop a round when the hinge stops holding.

</details>

<details>
<summary>🧘 MORNING FLOW + BARRE — 10-15 min, no equipment</summary>

**The most preservable thing you have.** Protect this before anything else.

| Block | What |
|---|---|
| **Primer** ~3 min | Dead hang · scapular pulls · shoulder openers |
| **Work** ~5 min | Push-ups · core · plié pulses · relevés · glute floor work |
| **Flow** ~7 min | Flowing yoga transitions, straddle + hip openers |

**Rehab anchors that always stay:** prone Y-raise, scapular push-up, wall angel, side-lying ER, dead hang, scapular pull.
**Barre works on the mat space** and costs almost nothing neurologically — the right call on a no-sleep day.

</details>

<details>
<summary>✅ WEEKLY COVERAGE — the actual target</summary>

Forget days. Touch each once over any rolling week.

| Pattern | Covered by |
|---|---|
| Vertical pull | Pull-ups, dead hangs |
| Horizontal pull | DB row, chest-supported row, KB row, any flow with a row |
| Push | Incline DB press, push-ups, KB press |
| Squat | Goblet, KB front squat, Bulgarian, leg press |
| Hinge | Swings, RDL, Nordic, any flow with a clean |
| **Carry** | Farmer carry, suitcase carry — **the feed bags don't count**, they're weekly-ish and not training |
| Core / anti-rotation | Figure-8, windmill, bent press, barre floor work |
| Shoulder health | Face pull, band work, prone Y, dead hang |

**Only got three? Make them vertical pull, push, shoulder health.**

</details>

<details>
<summary>🛑 BAD-SLEEP RULES</summary>

| Cut hard or skip 🛑 | Keep 🔥 |
|---|---|
| Overhead pressing, snatches, bent press | Machines, isolation, floor work |
| Heavy swings, heavy hinging | Flows and mobility |
| Anything where the cue breaks | Morning flow — always |

**The test:** if you can't hold the cue — shoulders packed down, ribs down, spine neutral — the load is wrong *today*.

**Carries still need doing.** The feed bags are once a week or every other — real load, but not a workout.

</details>
