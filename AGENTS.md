# WOD agent entry point

Read [CLAUDE.md](CLAUDE.md) before project work. It is the shared source of WOD's
project and coaching rules, regardless of which agent is running; keep those
rules there rather than duplicating them here.

For smolbox setup, "is the box up to date?", local/box file exchange, or Ask
snapshot questions, read [the WOD smolbox guide](docs/guides/smolbox-workflow.md).
Identify your checkout first. A status question authorizes inspection, not
automatic sync, reset, snapshot refresh or deployment. Inside the VM, do not
claim to have checked the separate Mac checkout unless you actually can.
