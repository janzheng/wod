# Daily Max-ish Pushups, Never to Failure — "Greasing the Groove"

**Date:** 2026-06-16
**Source:** [@yajnshri on X](https://x.com/yajnshri/status/2064900187135660367) — video post. Claim: do max pushups every day, never to failure, "apparently helps."

## What it actually is

This is **greasing the groove (GtG)** — Pavel Tsatsouline's term. Practice a movement frequently at submaximal effort, treating strength as a skill. Not a new fad; a long-established method.

## Does it work? Yes, with fine print.

**Why it works:**
1. **Strength is partly a skill** — frequent practice trains the nervous system (motor-unit recruitment, neural drive, coordination), not just muscle.
2. **Volume accumulates** — many small daily sets = large weekly volume, the main driver of hypertrophy/strength.
3. **Never-to-failure is the mechanism, not a footnote** — failure dumps fatigue that blocks daily repetition. Staying ~2-3 reps in reserve keeps the movement low-fatigue and therefore *daily-able*. Proximity-to-failure research: you don't need failure for gains, and avoiding it enables the frequency. Pushups are bodyweight + no spinal load → recoverable daily for most people.

**The catch:**
- **Bounded by bodyweight.** Builds the pushup + endurance well; raw-strength stimulus tapers once pushups get easy. To keep gaining you must make it *harder* (decline, archer, deficit, weighted, slower tempo) — not just add reps.
- **"Max but never to failure" is fuzzy.** Real meaning: high reps, stop a couple short. Literal daily true-max → unsustainable junk fatigue.

## Application to the program

- **Fits the ethos.** "Hard becomes easy / the floor rises" IS greasing the groove. Aligns with fuzzy progression — not number-chasing. Pushups already live in the morning-flow work blocks.
- **Shoulder caveat (this user specifically).** Daily pushups = daily front-shoulder loading; the bottom is a loaded front-delt stretch (same caution as dips). Given the right-shoulder history: keep genuinely submaximal, elbows ~45° (not flared), "pack down not up," scap moving freely; back off on cranky days rather than pushing through.
